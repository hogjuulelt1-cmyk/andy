# Лангуу

Захын ногоо, хүнсний бөөний худалдаачдыг (лангуу) ресторан, дэлгүүр, айл өрхтэй холбож
онлайнаар захиалуулж хүргүүлдэг апп. Static PWA, build step байхгүй, Vercel дээр `main`
руу push хийх бүрт deploy хийгдэнэ. UI монгол хэлээр; хэрэглэгчтэй монголоор ярь.

- `index.html`: бүх CSS/JS, дүрүүд (захиалагч, худалдаачин, хүргэгч, судалгаа).
- `engine.js`: DOM-оос хамааралгүй тооцоолол: хиймэл зах, эрэлтийн таамаг, хэрэглэгчийн
  завсрын загвар, үнийн байрлал, найдвартай байдал, зүй бус хэв маягийн тест, сагсны
  хувилбарууд. Node дээр `require` хийж тестлэж болно.
- `schema.sql`: олон хэрэглэгчийн хувилбарын Supabase схем (RLS-тэй). Одоогийн апп
  localStorage ашигладаг, Supabase хараахан холбогдоогүй.
- `docs/HISTORY.md`: өнөөдрийг хүртэл юу хийсэн, яагаад, дараа нь юу хийх. Шинэ сешн
  эхлэхдээ эхлээд үүнийг унш.

## Ажиллах дүрэм

- Хувилбар бүрт `engine.js?v=N` болон хөлний "Туршилтын хувилбар N" дугаарыг нэмэгдүүл
  (кэш хүчингүй болгох).
- Push хийхийн өмнө: `python3 -m http.server` ажиллуулж Playwright-аар iPhone 13 хэмжээнд
  цайвар/бараан горимд ачаал: page error алга, хэвтээ гүйлгээ алга, input 16px.
- `engine.js`-ийн загварын өөрчлөлтийг Node дээр хиймэл зах дээр шалга: шударга (хэв маяггүй)
  өгөгдөл дээр хуурамч дохио өгөхгүй, нуусан хэв маягийг олдог байх.
- Нэр, өнгө, дизайн түр зуурынх; хэрэглэгч хожим солино гэсэн.
