# Лангуу

Захын лангуунаас ресторан, дэлгүүр, айл өрх рүү онлайн захиалга, хүргэлт. Хоёр талдаа
суралцдаг загвартай: захиалагчид хямд, найдвартай, хурдан сагс; худалдаачинд эрэлтийн
таамаг, нөөцийн зөвлөмж, байнгын хэрэглэгч, алдах эрсдэл.

Ажиллуулах: ямар ч static server (`python3 -m http.server`), build хэрэггүй.
Deploy: Vercel, репог холбоход л хангалттай.

Дэлгэрэнгүй: `CLAUDE.md` (ажиллах дүрэм), `docs/HISTORY.md` (түүх, шийдвэр, дараагийн алхам).
