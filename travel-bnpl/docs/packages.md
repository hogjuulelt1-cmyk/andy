# Standard packages (seed content)

Prices are **2026 estimates per person in KRW**, assuming 6 people share one vehicle (Purgon / Delica) with driver, Korean-speaking guide and cook. Verify with real suppliers before launch.

## 1. Gobi — 7 days 6 nights (most popular)

| Day | Plan                                                                              | Stay             |
| --- | --------------------------------------------------------------------------------- | ---------------- |
| 1   | Incheon → Chinggis Khaan Intl Airport. UB, Sukhbaatar Square, Mongolian dinner.   | UB hotel         |
| 2   | UB → Tsagaan Suvarga (Dundgovi), "Mongolian Grand Canyon", sunset.                | Ger camp         |
| 3   | → Yolyn Am (Gurvansaikhan), ice canyon, hike.                                     | Ger camp         |
| 4   | → Khongoryn Els, camel ride, sand dune sunset.                                    | Nomad family ger |
| 5   | → Bayanzag (Flaming Cliffs, dinosaur fossils), **stargazing** (Korean #1 reason). | Ger camp         |
| 6   | → Ongi monastery or Baga Gazriin Chuluu, towards UB.                              | Ger camp         |
| 7   | UB → Incheon.                                                                     | –                |

| Cost item                            | KRW               |
| ------------------------------------ | ----------------- |
| Flight ICN–ULN return (summer)       | 500,000 – 900,000 |
| Vehicle + driver + guide + fuel (÷6) | 350,000 – 450,000 |
| Ger camps + meals, 6 nights          | 250,000 – 350,000 |
| Camel, tickets, misc                 | 50,000            |
| eSIM, insurance                      | 40,000            |
| **Total**                            | **~1.2 – 1.8M**   |

## 2. Terelj + Hustai — 4 days 3 nights (short, for workers)

| Day | Plan                                                                            |
| --- | ------------------------------------------------------------------------------- |
| 1   | Arrive, drive to Terelj (1.5h). Turtle Rock, horse riding. Ger camp.            |
| 2   | Aryapala meditation temple, Chinggis Khaan statue (Tsonjin Boldog). Stargazing. |
| 3   | Hustai National Park (Przewalski horses) → UB, Gandan monastery, Zaisan.        |
| 4   | Cashmere shopping, State Department Store → fly home.                           |

**Price:** ~0.8 – 1.2M KRW incl. flight.

## 3. Khuvsgul — 6 days 5 nights (summer, Jun–Aug)

| Day | Plan                                                                   |
| --- | ---------------------------------------------------------------------- |
| 1   | Arrive UB.                                                             |
| 2   | UB → Murun flight (or 12h+ drive) → Khatgal.                           |
| 3–4 | Lake Khuvsgul: horse riding, kayak, optional Tsaatan reindeer herders. |
| 5   | Murun → UB.                                                            |
| 6   | Fly home.                                                              |

**Price:** ~1.4 – 2.0M KRW incl. domestic flight.

## Add-ons (high margin)

- Naadam tickets (Jul 11–13), sell early.
- Drone / camel / horse photo shoot, deel costume photos.
- Airag tasting, khorkhog BBQ.
- Winter packages: Khuvsgul Ice Festival (Feb–Mar), Terelj snow.

## Marketing hooks

Stars, steppe, ger. Korean Instagram/YouTube interest in Gobi trips has grown fast since 2023. Peak season Jun–Sep; flights, vehicles and camps sell out early.
